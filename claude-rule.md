# Screen recordings as requests (SRTC)

When a message is a plain transcript with numbered markers like `[1]`, `[2]` and the same number of screenshots attached,
it comes from my screen+voice recorder: the spoken words ARE my request.
- `[n]` sits right after the word I was saying when I pointed at, circled or clicked something; screenshot n (in attachment
  order) shows the screen at that moment, cursor boxed in red. Use it to resolve "this", "here", "that one".
- Carry the request out directly. Ask one question only if it is genuinely ambiguous; otherwise state your assumption in
  one line and proceed.
- When I say "first … then …", follow that order. Several requests → do them in the order spoken, report each in one line.
- The older format (a "Screen recording request (SRTC)" header with tiled sheets stamped mm:ss and a DIGEST.md) means the
  same thing: narration = request, frames = context.
